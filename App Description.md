Monitoring tool (Octometer) features.

Locally deployed web app.
The app will display a table.
On top level each row represents an app, shows total number of clicks, total number of unique users, total number of unique sessions.
Click on a row opens the second level, where each row represents a user and shows clicks, sessions, unique elements interacted with.
Click on the second level row opens the third level where each row represents an element interacted with, shows clicks, sessions, last interaction timestamp.

This web app will poll the other apps periodically (each 5 seconds in dev mode, each 1 minute in prod mode).
Each app will have to provide an endpoint for the Monitor to gather the metrics information.
The metrics endpoint will have a standard contract for all the apps.
The metrics endpoint will check the key sent to it by the monitor.
Each app will have a separate key, that is generated by the monitor and stored in an app.
The metrics information will be stored in each apps' database in a standardized format as event log (no grouping, references etc whatsoever).
The metrics gathered will be clicks (taps) on the element with timestamp, element name (id), session id, username, ip address.
